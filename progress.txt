Task 1 (Complete Quiz Log): Added a QuizLogEntry type to the store that records every quiz attempt with timestamp, type, itemId, and isCorrect. Updated recordQuizAttempt to append entries to stats.quizLog. Added version 3 migration. Added a "Complete Quiz Log" section to the stats page showing a filterable, paginated table (newest first) of all quiz attempts with type badges, item labels, and correct/wrong indicators.
Task 2 (Letter Sound Buttons): In WordsQuiz, restructured each word choice to render individual letter buttons below the word (e.g. DOG → [D][O][G]). Each letter button plays the corresponding phoneme sound from /sounds/phonemes/{letter}.wav when pressed, using stopPropagation so clicking a letter doesn't select the word. Letter buttons remain active even during incorrect/lockout states so the child can sound out words freely.
Task 3 (Large Quiz Text): Increased font sizes across all three quiz components. WordsQuiz: header text-2xl→text-4xl, word choice buttons text-2xl→text-6xl, letter buttons text-sm→text-xl. MathQuiz: header text-xl→text-4xl, question text text-4xl→text-7xl, answer choice buttons text-6xl→text-8xl. PhoneticsQuiz: header text-2xl→text-4xl, letter choice buttons text-6xl→text-8xl.
Task 4 (Remove Numbers Quiz): Removed the math/numbers quiz entirely. Deleted MathQuiz import from QuizContainer. Removed 'math' from QuizType union, stats state, enabledQuizTypes default, and partialize config in the store. Added version 4 migration to strip math from persisted state. Removed math checkbox and difficulty selector from settings page. Removed math stats card and log filter from stats page.
Task 5 (Android-style Interval Input): Replaced the `type="number"` browser input for "Minutes between Quizzes" with a stepper control featuring large −/+ buttons flanking the current value. Value is clamped between 1 and 60 on each tap, giving a familiar and easy-to-use Android-style experience.
Task 6 (Fix Vercel Build): Discovered ltmain.sh in the project root was a symlink to /opt/homebrew/Cellar/libtool/2.5.4/share/libtool/build-aux/ltmain.sh. On Vercel, the symlink target doesn't exist, causing ENOENT when Next.js stats the file during build. Fixed by removing ltmain.sh from git tracking and adding it to .gitignore.
Task 7 (Short Letter Sounds): Changed the letter buttons under each word choice in WordsQuiz to play `/sounds/short-sounds/{letter}-short.wav` (the pure phoneme sounds) instead of the longer phoneme files from `/sounds/phonemes/`. Added a fallback to the phonemes folder for any letters that don't have a short-sound file. Also removed the broken ltmain.sh symlink from disk (not tracked by git) that was still causing `npm run build` to fail, and installed the missing `lightningcss-linux-arm64-gnu` native binding to fix the Turbopack build.
Task 8 (Fix Cross-Platform Build for Vercel): Removed `lightningcss-linux-arm64-gnu` from `dependencies` in package.json. This package is a platform-specific native binary for Linux ARM64 and was incorrectly listed as a hard dependency (added when the project was modified in an ARM64 Linux Docker container). Vercel runs on Linux x64, so npm refused to install it. The `lightningcss` package itself manages its own platform-specific optional dependencies automatically, so the explicit entry was unnecessary. `npm run build` now succeeds cleanly.
